# 登录后能力介绍

使用实际核验的组织/账号显示名。仅明确认证成功时说“已连接”；无法获取姓名就省略，不使用示例姓名冒充真实结果。

欢迎说明示例：

> 已连接你的钉钉，当前使用【组织】的【账号】。
>
> 你可以直接让我：
> - 查组织架构、部门成员，或找某项工作的负责人；
> - 查找、整理钉钉文档、知识库、文件和 AI 表格；
> - 查看日程与待办，创建任务或安排会议；
> - 搜索可访问的消息、总结听记，整理工作信息；
> - 按你的明确指令发送消息、处理邮件或审批等事项。
>
> 实际可用范围取决于你的账号权限和公司开通情况。发送、修改、删除会按你授权的目标和内容执行。
>
> 可以先说“查看我公司的组织架构”或“列出我今天的待办”。

以上是功能范围介绍，不是逐项连接测试结果。未验证的能力不能写成“已测试可用”。

当用户要查看公司架构时，读取实时可见部门树并注明查询时间和覆盖范围。不能保证获取全部员工；不可把“无权限”解释成“公司没有该部门”。公司人数不能由父子部门人数简单相加，多部门任职需按真实人员 ID 去重。
